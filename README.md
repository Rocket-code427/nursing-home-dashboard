# 养老院项目 - 数据看板

## 项目结构

```
nursing-home-dashboard/
├── index.html          # 看板主页面
├── data.json           # 数据文件（由同步脚本生成）
├── sync.py             # 飞书 Base 数据同步脚本
└── README.md           # 使用说明
```

## 技术栈

- Vue 3 (CDN) - 响应式框架
- Tailwind CSS (CDN) - 样式
- ECharts (CDN) - 图表
- 纯静态，无需构建工具

## 数据源

飞书 Base：`养老院项目-设备接入排期-v2`
- 表1「全部设备排期」：设备名称、各节点完成状态
- 表2「节点任务」：40条记录（8设备 × 5节点）
- 表3「会议纪要」：会议编号、日期、摘要

## 数据同步

```bash
python sync.py  # 从飞书 Base 拉取数据，生成 data.json
```

## 部署

1. 本地打开：`open index.html`
2. 或部署到 Cloudflare Pages / GitHub Pages

## 看板内容

1. **顶部概览**：总进度、设备完成数、风险数
2. **设备进度甘特图**：8台设备 × 5节点
3. **节点状态矩阵**：颜色标记（已完成/进行中/待开始/滞后）
4. **P0 风险预警**：待确认事项、滞后节点
5. **会议纪要**：最新会议摘要
